# Rogue Trader (Unofficial) — система для Foundry VTT

Неофициальная фанатская адаптация системы правил **Rogue Trader** от Fantasy Flight Games для [Foundry Virtual Tabletop](https://foundryvtt.com).

Проект развивается добровольно, несколькими фанатами системы. Все права на вселенную Warhammer 40,000 и систему правил Rogue Trader принадлежат Games Workshop и Fantasy Flight Games. Некоммерческий проект: платное распространение запрещено.

## Статус

**Этап 1 — каркас системы и механика бросков (готово):**

- Система устанавливается и запускается в Foundry VTT **v14**.
- Базовый тест d100: **успех, если бросок ≤ цель**, с модификатором ±N.
- **Степени успеха/провала** по правилам RT Core: каждая полная десятка разницы между модифицированной целью и броском равна одной степени.
- **Критические результаты**: натуральная 01 — критический успех, натуральная 100 — критический провал (в режиме 2d10: 0+1 и 0+0), независимо от цели.
- Два режима броска стогранника:
  - **1d100** — обычный стогранник;
  - **2d10** — стогранник из двух d10: первый куб — десятки, второй — единицы; выпадение 0+0 читается как **100**.
- Диалог броска: цель и модификатор. Режим броска задаётся только глобальной настройкой системы.
- Чат-карточка: выпавшие кости (в режиме 2d10 оба куба отдельно), итог, цель, УСПЕХ/ПРОВАЛ.
- Типы актёров: **Персонаж**, **NPC**, **Корабль**, **Колония**.
  - Лист персонажа/NPC: вкладки **Навыки · Бой · Псайкана · Корабль · Журнал · Опыт · Настройки**.
  - Шапка листа: имя персонажа, имя игрока, Очки Судьбы и Усталость (степперы при наведении, всплывающие подсказки по правилам), кнопки быстрого броска 1d5 и 2d10, тумблер штрафа усталости (-10 ко всем характеристикам, лимит усталости = бонус Выносливости).
  - Характеристики в одну линию: базовое значение + текущее (клик — бросок); штраф усталости отражается в значениях.
  - Вкладка «Бой»: раны со степперами.
  - Вкладка «Опыт»: улучшения характеристик (+0…+20 с шагом 5), базовое значение, автоматический бонус (десятки) и модификатор бонуса (неестественная характеристика).
  - Вкладка «Настройки»: переключение редакции правил (пока — Rogue Trader).
  - Лист корабля и колонии — заглушки (реализация на этапе 4).
- Типы предметов: **Оружие**, **Броня**, **Снаряжение**, **Боеприпасы** (лист предмета — заготовка).
- Настройки системы: режим бросков (единственное место переключения 1d100 / 2d10) и редакция правил.
- Локализация русский/английский, выбор языка — стандартная настройка клиента Foundry (у каждого игрока своя).

**Дальнейшие этапы:**

- **Этап 2** — полноценный лист персонажа (Игрок/NPC): навыки, таланты, снаряжение, боевка, оформление.
- **Этап 3** — компендиумы предметов (броня, оружие, снаряжение), добавление своих предметов по типу, перетаскивание в листы персонажей.
- **Этап 4** — листы корабля и колонии.

## Установка

**Для разработки / тестирования:** скопируйте репозиторий в папку данных Foundry:

```
<FoundryData>/systems/rogue-trader
```

например `git clone https://github.com/ppovolotsky/FoundryVTT-Rogue-Trader-Unofficial.git "systems/rogue-trader"`, затем перезапустите Foundry и создайте мир с системой «Rogue Trader».

**Обычная установка:** через установку по манифест-ссылке:

```
https://raw.githubusercontent.com/ppovolotsky/FoundryVTT-Rogue-Trader-Unofficial/main/system.json
```

## Релизы и обновления

Релизы собираются автоматически: пуш тега `vX.Y.Z` запускает GitHub Action, который проверяет, что версия в `system.json` совпадает с тегом, собирает `system.zip` и публикует релиз. Ссылки в манифесте постоянные, поэтому Foundry обновляет систему без переустановки:

1. Установите систему один раз по манифест-ссылке выше.
2. Когда выходит новая версия, на экране настройки Foundry (Setup → Game Systems) появится «Update Available» — нажмите кнопку обновления: Foundry сам скачает архив последнего релиза и применит его. Скачивать и переустанавливать систему вручную не нужно.

Порядок выпуска новой версии: поднять `version` в `system.json` → закоммитить → создать тег `vX.Y.Z` на этом коммите → запушить `main` вместе с тегом. Релиз опубликуется сам.

## Использование

- Клик по характеристике в листе персонажа открывает диалог броска (цель = значение характеристики).
- Макросы и API:

```js
// Бросок с ручной целью (режим — из глобальной настройки системы)
await game.rogueTrader.roll({ target: 45, label: "Тест" });

// Бросок с модификатором; режим можно переопределить только макросом
await game.rogueTrader.roll({ target: 45, modifier: -10, mode: "2d10" });

// Только диалог (режим всегда берётся из глобальной настройки)
await game.rogueTrader.rollDialog({ target: 45, label: "Навык оружия" });
```
